# Knowledge base

Plain-text files describing how the business runs. Claude reads these before it answers.

| Folder / file | One file per... | Template |
|---|---|---|
| `company/` | topic (overview, team, partners, goals) | `company/overview.md` |
| `services/` | service or product | `services/_template.md` |
| `processes/` | process | `processes/_template.md` |
| `vendors/` | trade or vendor | `vendors/vendors.md` |
| `policies/` | policy area (deposits, cancellations, warranties) | `policies/_template.md` |
| `calls/` | call (notes or transcript) | none |
| `voice.md` | n/a | how we write to customers |
| `roadmap.md` | n/a | process inventory and plan |

Files that start with `_` are templates. Copy them, don't fill them in.
No customer personal info in here (card numbers, bank details, anything sensitive).
