# Map a process

1. Ask which process to map if it isn't clear. Check `knowledge/processes/` for an existing file and continue it instead of starting over.
2. Read `knowledge/processes/_template.md` and anything in `knowledge/` related to this process.
3. Interview the owner **one question at a time**, section by section through the template. Short questions. Offer examples when a question is abstract.
4. Save progress to the file after each section so nothing is lost if the chat ends.
5. Never invent steps, numbers, or rules. Anything unanswered goes under Open questions.
6. When the current state is complete, propose the Future state table (AUTO / AI DRAFT / HUMAN, one-line reason each) and ask the owner to confirm or change it.
7. Add the mermaid flow diagram.
8. Update the matching row in `knowledge/roadmap.md` (status, hours, pain).
9. End with what's still open, and whether it's ready for a pilot brief (prompt 04).
