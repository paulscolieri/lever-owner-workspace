# 02. Voice memo to SOP

Goal: turn a 10-minute walk-and-talk into a clean process doc.

Record yourself explaining how you handle something (your phone's voice memo app transcribes, or use any dictation tool). Then paste the transcript in:

```
Here's a voice memo transcript about how we handle [process name, e.g. a new quote request from the website].

Turn it into a process doc in knowledge/processes/ using knowledge/processes/_template.md.
- Keep my rules and exceptions exactly. Don't add steps I didn't say.
- Mark anything unclear as an open question instead of guessing.
- If it mentions prices, vendors, or policies, save those to the right files in knowledge/ too.
- If a related file already exists, update it instead of creating a new one.
Then ask me the 3 most important questions that would make this complete.

Transcript:
[paste here]
```

Good topics to start with:

- How you quote a job, from the first inquiry to a sent quote
- What happens between "yes" and the job being scheduled
- How a job runs on the day, and who does what
- Invoicing, deposits, and chasing late payments
- Hiring and onboarding someone new
- The question customers ask most, and how you answer it
