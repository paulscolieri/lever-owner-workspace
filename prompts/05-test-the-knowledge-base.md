# 05. Test the knowledge base

Goal: find the gaps by asking the questions customers actually ask.

```
Act as a prospective customer. Ask me 10 realistic questions, one at a time, the kind that come in by email, phone, or the website form (price, timing, what's included, deposits, warranties, what you need from them, etc.).

For each one, answer using only knowledge/. If the answer isn't there, say "NOT IN KNOWLEDGE BASE," then ask me for the answer and save it to the right file.

At the end, list what you added and what's still missing.
```

Do the same for a process:

```
Act as a new hire on their first day, following knowledge/processes/[name].md. Walk through 10 different real-world cases, from routine to messy. For each one, say what you'd do and which file told you. Flag every case where the knowledge base doesn't give a clear answer, then ask me and save the answer.
```
