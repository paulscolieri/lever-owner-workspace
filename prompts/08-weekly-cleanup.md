# 08. Weekly cleanup

Goal: keep the knowledge base accurate and small as it grows. 10 minutes a week.

```
Do a weekly review of this workspace:
1. Find duplicate or contradicting info across knowledge/ and propose merges.
2. List every open question across all files, grouped by file, so I can answer them in one sitting.
3. Flag anything that looks out of date (old prices, old dates, vendors we stopped using).
4. Check CLAUDE.md is still short and accurate.
5. Suggest one thing I keep doing by hand that should become a skill or a script.
Show me the list first. Don't change anything until I say which items to fix.
```

Then:

```
Commit and push everything we changed this week with a clear message.
```
