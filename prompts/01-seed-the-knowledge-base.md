# 01. Seed the knowledge base

Goal: get the basics of the business written down in an hour, by being interviewed instead of writing.

```
I want to build out the knowledge base in knowledge/. Interview me, one question at a time, starting with the company (knowledge/company/), then what we sell (one file per service or product in knowledge/services/, using knowledge/services/_template.md), then vendors and policies.

Rules:
- Ask one question at a time and wait for my answer.
- Keep my wording where you can. Don't invent anything I didn't say.
- After each section, save what you have to the right file and show me a short summary.
- Keep a list of open questions at the bottom of each file for anything I skipped.

Let's start with the company.
```

## Shortcut: bring in what you already have

If you have docs, price sheets, spreadsheets, or old Claude chats with useful info, drop the files into a new `inbox/` folder here and use this instead:

```
Read everything in inbox/. Sort what's useful into the right files in knowledge/ (company, services, vendors, policies, processes). Show me the plan of what goes where before you write anything. Don't copy customer personal info.
```

To export old browser chats: in claude.ai, open a chat and ask it to "summarize everything in this chat I'd want to keep as a markdown document," then save the result into `inbox/`.
